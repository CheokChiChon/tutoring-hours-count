# Tutoring Hours Count

一個手機優先的 PWA，用來記錄補習時數並自動計算 MOP 薪金。

## 功能

- 建立學生及每位學生的時薪
- 記錄補習日期、學生和時數
- 自動計算每筆補習薪金
- 每月統計總時數、總薪金和未收款
- 單筆或按學生把本月記錄轉為已收款
- 勾選多位學生計算總薪金
- 第一次打開後可離線使用
- 保存備份，日後可用備份還原資料
- 下載所選月份的補習表格

## 使用方法

直接打開 `index.html`，或部署到 GitHub Pages 後用手機 Safari 加入主畫面。
第一次成功打開 GitHub Pages 版本後，之後沒有網路也可打開 App。

資料只保存在目前手機/瀏覽器，建議定期在「統計」頁底部保存備份。
